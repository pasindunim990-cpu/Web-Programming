# Week 01 answer

The site has two separate pages, a shared external stylesheet, header, navigation, main content, side column and footer. Flexbox creates the columns on wider screens. Media queries stack the columns on small screens, and images use `width: 100%` and `height: auto` so they remain visible. There is no JavaScript or CSS framework. Open `index.html` to start. Internet access is needed for the example photographs; the layout still works if they do not load.
