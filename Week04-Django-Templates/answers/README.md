# Week 04 answer - ORM, URLs and templates

This folder is a set of matching files for the University example used in the tutorial. Create a project and app called `myApp`, add it to `INSTALLED_APPS`, and use the models from Week 03's supplied `code/models.py` (or the model definitions below). Put the Python files in the app and the HTML files in `templates/`. The app URL namespace is `myApp`. The examples show `all()`, `get()`, relationship iteration, a home page and a student details page with a 404 response.
